# modul registration

## Tanggung jawab

Mendaftar akun di aplikasi cakrawala suruh untuk kemudahan login aplikasi dan memvalidasi akun di aplikasi cakruh

# Data

- Pemilihan metode pendaftaran
- Verifikasi otenntikasi (OTP)
- Pengisian Profil & kemanan
- Pengaturan lokasi
- Aktivasi & Dasbor

# Aturan

- Pendaftaran otomatis ke aplikasi cakruh
- Pendaftaran dinyatakan berhasil jika data verifikasi berhasil
- mengisi profile sebagai bukti bahwa mahasiswa cakrawala yang login
- menentukan lokasi agar petugas tau bahwa mahasiswa berada di lingkungan kampus
