# Modul Notification

# Tanggung jawab

Setelah memesan jasa dalam aplikasi, admin akan mengirimkan notifikasi bahwa petugas akan menuju lokasi yang sudah di tentukan oleh mahasiswa

# Data

- Notifikasi aplikasi
- Maps petugas
- Notifikasi pembayaran berhasil
- Notifikasi pengerjaan selesai

# Aturan

- Mengirim notifikasi ke pemesan
- Memantau apakah petugas sudah berangkat menuju lokasi atau belum
- Memberi tahu bahwa pembayaran telah sukses
- Memberi tahu bahwa pengerjaan telah selesai

# Hubungan

- Modul booking (saat selesai memesan jasa)
- Modul payment (saat selesasi melakukan pembayaran)
- Modul registration (mengirim notifikasi berhasil login)
